# 顾问目的地检索

需求单把必选国家、区域背景、举例和排除目的地分开保存。“德法意瑞”展开为四个必选国家；已有这些具体国家时，“欧洲、西欧”不再额外要求线路名称出现相同字样。明确举例只参与排序，明确排除会过滤候选。无结果时保留原条件，由顾问决定是否放宽。

模型提议先检查本轮原文依据与权限，再由服务端统一解释；顾问手动修改的值保持优先。没有说明年份的整月需求按业务日期换算，并标为推断。四位客人只保存总人数，不推断成人、儿童或房型。

目的地词表使用国家、城市、区域和旅游组合简称。检索仍使用现有 PostgreSQL 投影与权限规则。国家信息记录来源：线路名称是候选依据，供应商结构化字段是声明，适用的已复核行程或商户确认标签才是已确认依据。出发机场和营销描述不能证明游览覆盖。

只有全局适用的已复核发布稿可补充通用国家信息；仅适用某日期或出发地的行程，在选定团期前保持未知。投影保存源版本、展示版本、内容版本、发布稿标识和词表版本，过期时使用同样的实时规则。商户已批准的目的地排除标签在同步后继续生效。

第一次检索最多展示三条线路，通过“更多”读取其余候选；日期条件要求窗口内存在已发布团期，但不据此承诺价格、余位或可报名。顾问选定线路后才看团期，再选择团期并补足资料后询价。

## 验证

自动用例覆盖四国简称、明确举例、排除国家、中文月份与跨年、来源校验、完整分页、过期投影、权限撤销、出发机场区别、未复核内容和行程适用范围。提交的业务数据均为虚构 ACME 内容。

真实模型验收使用独立测试账号，原始回复与供应商线路只保存在私有验收目录。发布验收记录应包含重复原问、不同表述、完整分页和选线推进结果。

## 发布

迁移 `0039_destination_projection` 前停止 API 与写入 Worker，备份数据库及私有文档并验证独立恢复，再迁移和刷新运行角色权限。镜像验收使用独立容器、虚构账号和无公开端口的网络。切换后核对原有目录选择、同步计划、上游冷却时间与库存流水，重建可恢复的搜索投影。

该迁移仅增加搜索字段。应用回退可以使用之前的镜像并保留新增列；不要通过删列或整库还原覆盖上线后的业务变更。数据恢复需要单独判断恢复点及新产生的数据。

分页结果保存服务端生成的范围与前后游标。“第一条”指当前连续展示列表的第一条；新检索会重置这个顺序，无法完整重建时使用线路按钮。找线路后的文字摘要仅使用服务端需求与页结果，明确区分“本页数量”和“还有更多”，不补写航班、价格或报名承诺。模型仍负责理解需求、选择查询工具和后续对话；卡片与查询进度继续实时展示，保存的会话摘要与页面一致。
