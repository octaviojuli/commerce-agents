# 顾问选线顺序验收

## 业务顺序

找线路 → 顾问选择一条线路 → 展示该线路团期 → 顾问选择一个团期 → 补齐询价资料并询价。

例如“4 位客人，11 月去 ACME 海湾，8 天左右”，首轮只返回至多三条线路卡片和简短说明。人数构成与房型未知不影响选线；也不默认把总人数当成人。报价所需字段即使齐全，首轮仍不自动选线或询价。

## 修复

原提示要求每轮提供真实团期，工具又将已查询线路当作可直接选中的线路，导致首次推荐后自动展开多个团期列表。旧验收检查接口成功和工具名称，没有验证实际卡片及顾问选择。

`advisor_flow.py` 从当前有效会话轮次读取顾问原话，与之前已完成轮次展示的线路或团期卡片匹配。唯一的序号、名称或日期选择才能推进；模糊指代、比较和否定不能授权模型自行选择。页面按钮继续使用已有的显式操作路径。验证失败时不保存选择，也不查询团期或报价。

线路详情只返回线路内容，不附带团期预览。目的地、时间、天数、出发城市或偏好变化时清除旧线路和团期选择，并使旧报价失效。

快捷回复成功完成后结束本轮，避免模型追加第二遍总结。窗口外团期保留页面折叠查看能力，模型结果说明中不展开这些日期。
