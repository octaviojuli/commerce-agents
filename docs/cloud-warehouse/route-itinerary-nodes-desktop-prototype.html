电脑端设计说明

  1. 数据和手机端完全相同，只是排布不同节点、字段、三种视图都和 H5 原型一致。电脑端利用更宽的屏幕，把手机上需要切换或弹出的内容同时摆出来。
  2. 左栏是简要行程，也是目录由节点自动生成。点某一天跳到对应位置；滚动中间内容时，左栏自动高亮当前这一天。
  3. 中间连续展示全部天数电脑上适合整篇阅读和打印前核对，不用像手机那样一天一屏。观光段的子景点排成两列，三餐和住宿放在每天右侧的窄栏里。
  4. 右栏随视图变化客户看：全程的费用提示（自费、购物、小费、不含项）汇总。顾问看：当天和需求单的冲突、原文未说明的字段。原文对照：当前这天的供应商原文，和节点左右并排对照。
  5. 左右对照是电脑端最主要的价值点中间的节点，右栏原文高亮对应句子；点原文里的高亮，中间滚到对应节点。商户审核和顾问核实主要在电脑上完成。
  6. 窄屏自动退化宽度小于 900px 时只保留中间一栏，和 H5 版本的阅读方式一致。
